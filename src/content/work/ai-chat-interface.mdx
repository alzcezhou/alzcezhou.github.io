>
  <p>enLabel makes packaging and labeling software, from label creation in e-Draw to regulated documents in eIFU. Every product wanted an AI assistant. I designed <em>one</em> chat window that works inside any of them, drawing on the data it's opened with.</p>
  <p class="text-[16px] leading-[1.55] text-body-2">First in-context application: e-Draw, enLabel's label creation software.</p>
</CsContext>

<CsSection id="principles" label="02 Principles · One shell, many products">
  <CsInsights>
    <CsInsight title="Context is visible">The top bar names the data source the AI is working from, so users know what it can see in each product.</CsInsight>
    <CsInsight title="Structure beats a blank box">Quick prompts and a prompt builder turn domain choices into a complete request.</CsInsight>
    <CsInsight title="Never a black box">Progress steps, a stop button and token cost show what the AI is doing and what it spends.</CsInsight>
  </CsInsights>
</CsSection>

<CsSection id="decisions" label="03 Key decisions">
  <CsAnnotated
    src="/images/ai-assistant/landing.png"
    alt="AI assistant window, empty state with quick prompts and prompt builder"
    well
    separator=": "
    heading="A prompt builder that writes the hard part"
    items={[
      { title: "Quick prompts", text: "one-tap starts for common jobs (product label, packaging, IFU, compliance check)" },
      { title: "Build Your Prompt", text: "document type, category and standard dropdowns" },
      { title: "Editable pills", text: "choices land in the composer as a sentence (\"Shipping Label for Organic Food following FDA 2026\") the user can still change or extend" },
    ]}
    why="In regulated labeling, a missing standard or category means a wrong label. Structured inputs make sure the critical details are in every prompt, without taking away free text."
  />
  <CsDecisions>
    <CsDecision
      title="The AI asks instead of guessing"
      problem="vague prompts produce confident but wrong output."
      decision="follow-up question cards with numbered answers, an &quot;Other&quot; field and paging (1 of X)."
      outcome="missing details get resolved before generation, in a few clicks."
    />
    <CsDecision
      title="Generation you can see and stop"
      problem="long AI tasks feel like a black box."
      decision="step chips (Read guidelines → Check compliance → Generate layout), an always-on Stop and token cost before and after."
      outcome="users know what's happening, what it costs and how to bail out."
    />
  </CsDecisions>
</CsSection>
